# 用户端点餐助手网页

直接用浏览器打开 `D:/sky-agent/web/customer/index.html`，不用启动 Python、Java、Nginx 或数据库。也不需要安装前端依赖。所有图片和脚本均为本地文件；浏览器策略禁止此演示页连接网络。

- **帮我选餐**：快捷按钮填入问题，可修改人数、预算、口味后发送。支持 1–6 人的本地演示菜单，缺参数或预算不足时给出提示。两人、预算 60 元、不辣示例的商品小计为 ¥53.00，不含打包和配送费。
- **查我的订单**：只显示两笔虚构订单。点击卡片可查看状态、份数和金额，按 Esc 或关闭按钮退出。不支持下单、支付、催单或取消。
- **新对话**：清空页面草稿和演示记录，不发服务端请求；失败时保留问题供重试。记录只存在于页面内存。

## 代码和验证

`web/customer/index.html`、`styles.css`、`bento.svg`负责页面与插画；`demo.js`负责虚构数据、选餐和对话状态；`app.js`处理表单、结果卡和订单弹层。该网页不引用小程序参考目录，也没有修改商家网页。

在项目目录运行 `node --test tests/web/core.test.mjs tests/web/customer-web.test.cjs`。本地浏览器可选验证脚本为 `node tests/web/customer-web-qa.cjs`，需要已安装的 Playwright 和浏览器；可用 `SKY_BROWSER_PATH` 指定现有浏览器。脚本打开本地文件，不监听端口，并检查没有发出 HTTP 请求。截图保存在 `output/playwright/`。

当前是产品交互演示，不是真实模型的回答。后续联调需要单独确定网页用户登录方式、部署方式和真实接口的数据结构；不复用商家 Token，不在浏览器中保存模型密钥。此前在外部参考目录制作的小程序演示不作为此网页版的依赖。
