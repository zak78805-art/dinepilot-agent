双端安全隔离清单（实测通过） ZERO-TRUST
  • 认证硬隔离：顾客 JWT 访问商家 8 个端点全部 401；管理员 JWT 访问顾客端 2 个端点全部 401。
  • 路径白名单：显式阻断 /admin/* 与旧 API 写副作用 GET /user/order/reminder/{id}。
  • 连接池零串号：共享 httpx.AsyncClient 不挂载默认鉴权头，每次请求由协程 ContextVar 独立注入。
  • PII 自动剥离：订单查询强制二次校验 record.userId == current_customer_id，剔除手机号、门牌与姓名。
  • 限流与配额防刷：按 (role, user_id) 滑动窗口限流与每日 Token 预算熔断，超限返回 429 + Retry-After。
