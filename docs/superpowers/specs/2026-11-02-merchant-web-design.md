# 商家经营助手网页设计（已确认）

目标：商家在现有管理端使用只读经营 Agent，无需粘贴 Token。

方案：完整 Vue 源码缺失，保留原编译文件；独立静态页位于 `/assistant/`，管理端侧栏由独立脚本追加入口。恢复 Vue 工程需重建依赖与构建，不纳入本轮。

页面沿用黄色品牌和深色侧栏，包含快捷问题、聊天、Markdown 表格、已执行工具、分析中状态、重试提示和返回管理端入口。Cookie `token` 仅在同源请求头中使用，不显示、不写入 URL、不另行持久化。没有凭证、401、403 时提示返回管理端登录，不自动删除其他登录状态。

Nginx 为 `/assistant-api/` 单独转发至 `127.0.0.1:8090/api/agent/`，保留原 `/api/` 到 Java 的转发。网页不含模型密钥，不启用跨域。聊天失败保持原问题可编辑，不自动重发；请求中禁用发送、快捷问题与新会话，防止并发和跨会话串答。网页记录在页面内存，刷新会新建会话ID；后端现有Agent上下文仍在服务进程内保留，非删除机制。登录凭证变化时清空网页记录并隔离在途结果。

模型内容作为不可信文本：仅支持安全 Markdown 子集（标题、段落、列表、强调、代码、表格），不执行 HTML，不加载模型提供的链接和图片。工具名称只显示后端实际返回记录，不把等待动画伪装成实时工具状态。

范围外：Vue 工程恢复、写操作、审批、持久化聊天、生产部署、JWT 密钥和有效期修改。兼容脚本依赖现有侧栏 DOM，将来更换管理端时需验证；找不到侧栏时不修改原界面，仍可直达助手页。

验收：Node 单元测试验证安全渲染、Cookie 解析、鉴权及错误映射、并发保护；浏览器用模拟网络验证真实 UI 成功/失败/过期凭证/移动布局/侧栏入口；Nginx 校验并实测页面和代理健康。Java、Agent 测试保持通过。模型数据链路已由此前 Apifox 联调，本轮不伪造身份或修改业务数据。
